# HomeControl 🏠

اپلیکیشن اندروید برای **کنترل وسایل برقی خانه با پیامک (SMS)**.
هر دکمه یک پیامک مشخص را مستقیماً از سیم‌کارت گوشی به شماره‌ی دلخواه شما می‌فرستد (مثلاً به ماژول GSM متصل به رله‌ها).

- Kotlin + Jetpack Compose + Material 3
- معماری MVVM، ذخیره‌سازی با Room و DataStore
- رابط کاملاً فارسی و راست‌چین، تم تیره/روشن، تاریخ شمسی
- بدون نیاز به اینترنت

> ⚠️ **وضعیت پروژه:** سورس کامل است، اما در محیطی که این پروژه ساخته شد امکان اجرای Gradle و کامپایل وجود نداشت.
> بنابراین **هنوز کامپایل و روی گوشی تست نشده است**. اولین Build را (در Android Studio یا GitHub Actions) انجام دهید؛
> اگر خطایی دیدید، متن خطا را بفرستید تا اصلاح شود.

## امکانات

| بخش | توضیح |
|---|---|
| صفحه اصلی | نام برنامه، شماره مقصد، وضعیت آمادگی (شماره/سیم‌کارت)، تعداد وسایل، کارت هر وسیله با دکمه‌های روشن/خاموش و فرمان‌های سفارشی، فیلتر دسته‌بندی |
| مدیریت وسایل | افزودن/ویرایش/حذف وسیله، آیکون، رنگ، دسته‌بندی، شماره اختصاصی، چند فرمان برای هر وسیله، تغییر ترتیب نمایش |
| دسته‌بندی | روشنایی، سرمایش و گرمایش، امنیت، سایر وسایل + ساخت/ویرایش/حذف دسته دلخواه |
| تنظیمات | شماره مقصد، کشور و پیش‌شماره، تم تیره/روشن/سیستم، صدای کلیک، مدیریت تاریخچه، پشتیبان‌گیری و بازیابی (JSON) |
| تاریخچه | نام وسیله، متن پیامک، شماره، تاریخ شمسی و ساعت، وضعیت ارسال |

### ایمنی ارسال
- قبل از **هر** ارسال، پنجره‌ی تأیید شامل نام وسیله، فرمان، متن پیامک و شماره مقصد نمایش داده می‌شود.
- قبل از اولین ارسال، توضیح داده می‌شود که برنامه چرا مجوز «ارسال پیامک» می‌خواهد و سپس مجوز درخواست می‌شود.
- جلوگیری از ارسال تکراری: یک فرمان را نمی‌توان کمتر از ۳ ثانیه بعد از ارسال قبلی دوباره فرستاد.
- اگر سیم‌کارت نباشد، خطا نمایش داده می‌شود و پیامکی ارسال نمی‌شود.
- متن هر فرمان باید در **یک پیامک** جا شود (در ویرایشگر بررسی می‌شود).

### وضعیت ارسال و تحویل (مهم)
- **«ارسال شد»** یعنی سیستم پیامکی گوشی پیامک را به شبکه تحویل داد (گزارش `sent` از اندروید).
- **«تحویل داده شد»** فقط وقتی نمایش داده می‌شود که **گزارش تحویل واقعی از شبکه** رسیده باشد. بعضی اپراتورها یا سیم‌کارت‌ها گزارش تحویل نمی‌دهند؛ در آن صورت چیزی نمایش داده نمی‌شود.

## اجرا در Android Studio

1. **Android Studio** نسخه‌ی Koala (2024.1) یا جدیدتر را نصب کنید (JDK 17 همراه آن است).
2. پوشه‌ی پروژه را با `File ▸ Open` باز کنید و صبر کنید Gradle Sync تمام شود.
   (برای Sync اولیه اینترنت لازم است.)
3. گوشی واقعی را با USB وصل کنید (گزینه‌ی USB debugging روشن باشد) و `Run ▸ Run 'app'` را بزنید.
   > شبیه‌ساز اندروید معمولاً سیم‌کارت ندارد؛ برای تست واقعی ارسال پیامک از گوشی واقعی استفاده کنید.

## ساخت APK

### روش ۱: Android Studio
`Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)`
فایل خروجی: `app/build/outputs/apk/debug/app-debug.apk`

### روش ۲: خط فرمان
فایل `gradle-wrapper.jar` در این پروژه نیست (فایل باینری است). یکی از این دو کار را بکنید:
- پروژه را یک بار در Android Studio باز کنید (خودش Gradle 8.9 را از روی `gradle-wrapper.properties` می‌گیرد)، یا
- اگر Gradle نصب دارید: `gradle wrapper --gradle-version 8.9` و بعد:

```bash
./gradlew assembleDebug
```

### روش ۳: ساخت خودکار APK با GitHub Actions (بدون نصب چیزی)
فایل `.github/workflows/build-apk.yml` آماده است. بعد از آپلود پروژه در GitHub:
1. به تب **Actions** مخزن بروید.
2. اجرای **Build Debug APK** (یا دکمه‌ی *Run workflow*) را باز کنید.
3. بعد از پایان، از بخش **Artifacts** فایل `HomeControl-debug-apk` را دانلود کنید و zip آن را باز کنید.

## نصب APK و مجوزها
1. APK را روی گوشی کپی و نصب کنید (اجازه‌ی نصب از منبع ناشناخته لازم است).
2. در **تنظیمات ▸ شماره تلفن مقصد** شماره را وارد و ذخیره کنید (مثلاً `09121234567`؛ با پیش‌شماره‌ی ایران خودکار به `+98912…` تبدیل می‌شود).
3. در اولین ارسال، توضیح و سپس درخواست مجوز «ارسال پیامک» نمایش داده می‌شود.

## نکات و محدودیت‌ها
- **دو سیم‌کارت:** برنامه از سیم‌کارت پیش‌فرض پیامک گوشی استفاده می‌کند (انتخاب سیم‌کارت در برنامه وجود ندارد).
- **شماره‌های کوتاه/پولی:** اندروید ممکن است برای شماره‌های کوتاه یک هشدار تأیید جداگانه نشان دهد یا ارسال را مسدود کند.
- **هزینه:** هر پیامک طبق تعرفه‌ی اپراتور حساب می‌شود.
- **فونت:** از فونت پیش‌فرض سیستم استفاده شده است. برای فونت دلخواه (مثلاً وزیرمتن) فایل `.ttf` را در `app/src/main/res/font/` بگذارید و در `ui/theme/Theme.kt` یک `Typography` با آن بسازید.
- **متن‌ها:** متن‌های رابط داخل کد Kotlin نوشته شده‌اند (برای سادگی). اگر بعداً چندزبانه خواستید، به `strings.xml` منتقل کنید.
- **حجم APK دیباگ:** به‌خاطر کتابخانه‌ی آیکون‌های Material زیاد است؛ نسخه‌ی release با R8 کوچک می‌شود.
- **امنیت:** هر کسی که گوشی شما را باز کند می‌تواند فرمان بفرستد. اگر فرمان حساس است (مثل باز کردن درب)، قفل گوشی را فعال نگه دارید و در ماژول گیرنده شماره‌ی مجاز تعریف کنید.

## ساختار پروژه

```
app/src/main/java/com/homecontrol/app/
├── HomeControlApp.kt        # Application + AppContainer (وابستگی‌ها)
├── MainActivity.kt
├── data/                    # Room (Entities, DAOs, Database), DataStore, Repository, Backup
├── sms/                     # SmsSender (SmsManager) + SmsStatusReceiver (sent/delivery)
├── util/                    # PhoneUtils (شماره‌ها)، DateFormatter (تاریخ شمسی)
└── ui/
    ├── AppNavigation.kt     # Navigation + نوار پایین
    ├── theme/               # تم Material 3 تیره/روشن، RTL
    ├── components/          # دکمه‌ی انیمیشنی، آیکون‌ها، حالت خالی
    ├── home/                # صفحه اصلی + ViewModel
    ├── devices/             # مدیریت وسایل + ویرایشگر
    ├── history/             # تاریخچه
    └── settings/            # تنظیمات و پشتیبان‌گیری
```

## ساخت نسخه Release (اختیاری)
برای انتشار باید APK را با keystore خودتان امضا کنید (`Build ▸ Generate Signed Bundle / APK`).
فایل‌های `*.jks` و `*.keystore` در `.gitignore` هستند؛ هرگز آن‌ها را در GitHub نگذارید.
